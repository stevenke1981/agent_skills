# 整理原則與初始邊界

這份資料庫依使用者提出的四個方向建立：盤點、分類、清楚描述與例外處理、儀表板及版本管理。

## 一物一用與分類

每個技能包保留自己的工作任務邊界，去重只限整包檔案完全相同的內容。同名版本或用途相近的技能不直接混合規則；保留來源與內容 hash，以客戶端、工具、產物及限制選擇。

主要分類包含資料與分析、日常與商業自動化、模板與框架、審查與驗證、除錯與應變。影音創作、開發與工程、平台與技能管理另外列類，保持資料庫可查找。初始自動分類會標記 heuristic，精修规则由 overrides 保留。

## 描述與例外

管理卡保留原始描述，抽出情境/觸發、意圖、產物、邊界、例外與相依工具。未找到明確資料則寫待確認，並加入改善清單。管理卡提供查找材料；真正執行時讀取完整原始技能與按需资源。

來源缺漏、版本衝突或不可用工具不會被當成「已準備完成」。unfinished placeholder 與缺少必要文件會與可查找技能分開，並保留原件待修；不以數量或靜態檢查代替任務驗收。

## 共享與版本

NAS 保存不可變原始物件與每次索引快照，所有电脑只需一次建立輕量查找入口。更新後重新查找便讀取中央当前版本。SQLite 不接受多电脑直接写入；發布由管理者持鎖、驗證後切換当前指標。
